# Посмотри в окно

Учебный проект Яндекс Практикума: стили для готового приложения «Посмотри в окно». Приложение ищет видео из окон по городу и времени суток и показывает их в плеере и списке карточек.

## Репозиторий

https://github.com/Shamil1585/posmotri-v-okno-ad

## Что сделано

- Раскладка страницы на flexbox, фиксированная ширина 1200px.
- Форма поиска: текстовое поле, кастомные чекбоксы на псевдоэлементах, кнопка «Найти».
- Список карточек с прокруткой, обрезкой заголовка и описания, состояниями `:hover`, `:active`, `:focus-visible`.
- Кнопка «Показать ещё», прелоадеры и блок ошибки поверх видео и списка.

## Технологии

HTML, CSS (flexbox, псевдоклассы и псевдоэлементы, `:has()`, `line-clamp`), JavaScript (уже написан в заготовке).

## Как запустить

Откройте `index.html` в браузере. Для работы поиска нужен доступ к интернету.
